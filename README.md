# UltimateArtifacts — Paper 1.21.11

Отдельный плагин и ресурс-пак для 10 артефактов. Требуется Java 21 и Paper 1.21.11.

## Сборка

Откройте папку в IntelliJ IDEA как Gradle-проект и выполните `gradle build` (или используйте Gradle из IDE). Готовый JAR появится в `build/libs/`.

## Установка

1. Скопируйте `build/libs/UltimateArtifacts-1.0.0.jar` в `plugins/`.
2. Перезапустите сервер.
3. Установите ресурс-пак из папки `resourcepack` на клиенте игроков или разместите ZIP на хостинге и настройте `resource-pack` в `server.properties`.

## Команды

- `/artifacts list`
- `/artifacts give <игрок> <id> [количество]`
- `/artifacts giveall <игрок>`
- `/artifacts reload`

Право: `artifacts.admin` (по умолчанию OP). Предметы не имеют рецептов и не выдаются обычным игровым путём.

## Серп пустоты

- ПКМ: Разрез пустоты (волна с уроном и притяжением)
- Shift + ПКМ: Гравитационная яма (контроль области)
- F / swap-hand: Теневой рывок
- Q / drop: Абсолютная пустота
- Убийства при наличии серпа в инвентаре накапливают души; следующий удар расходует накопление для бонусного урона (до 10 зарядов).

## Примечания

Это исходный проект первого этапа. Проверьте на тестовом сервере перед установкой на основной. Ресурс-пак использует `item_model` для Minecraft 1.21.11. Для раздачи игрокам нужен сам ZIP ресурс-пака; в этой папке лежит его исходная структура.


## Управление Серпом пустоты (обновление)

Серп больше не использует Q (выброс предмета) или F (смена руки). ПКМ открывает отдельное меню способностей, где умения выбираются кликом по слоту. Обычная атака ЛКМ остаётся обычной атакой серпа. Это исключает перехват клавиш выброса и смены рук.
